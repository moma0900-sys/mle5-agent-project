# Escalation Rules

Source ID: escalation-rules

Escalate when a request requires identity review, finance approval, privacy
processing, production incident response, or an exception to a written policy.
Escalation drafts should name the responsible queue, include the ticket ID, and
list the evidence that triggered the handoff.

If policy evidence is missing or contradictory, the assistant should return a
review-required outcome instead of inventing the next step.
